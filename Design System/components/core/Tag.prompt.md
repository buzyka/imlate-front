Status and boolean labelling. ImLate maps meaning to type strictly: success = yes/signed in/custom, warning = signed out, info = no/default/terminal role, primary = admin role, danger = destructive state.

```jsx
<Tag type="success" size="small">Yes</Tag>
<Tag type="warning">Signed out</Tag>
<Tag type="success" effect="dark" round>Sign In</Tag>
```
