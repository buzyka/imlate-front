The only chart primitive in ImLate. Flat, 6px tall, one colour on `--el-border-color-lighter`.

```jsx
<MiniBar value={18} max={20} intent="success" label="18 / 20" />
```

Intentional addition for the Attendance report's presence summary. No axes, no gradients, no animation, no multi-series — if a design needs more than a proportion, ask before inventing a chart language.
